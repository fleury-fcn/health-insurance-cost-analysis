# Notebooks

`01_walkthrough.ipynb` est une **visite guidée exécutée** des résultats : qualité des
données, EDA, inférence, ablation, modèles, interprétation et explication d'un profil.

Il est généré par `make notebook` (script `build_notebook.py`) à partir du package et des
artefacts du dernier `make run`. Il n'entraîne rien et ne contient aucun état caché :
la source de vérité reste le code testé dans `src/insurance_costs`.
