# Analyse et modélisation des coûts d'assurance maladie

Projet portfolio reproductible : audit, analyse statistique, modélisation
actuarielle et application interactive autour du jeu de données public
**Medical Cost Personal**. Le pipeline complet se lance avec :

```bash
make install
make run
```

Le rapport généré est disponible dans `reports/generated/report.html`.

> Projet en construction : les phases, choix méthodologiques, résultats et
> instructions de déploiement seront documentés au fil des commits.
